## 2024-05-18 - O(N^2) JSON stringification of reach matrix
**Mode:** Bolt
**Learning:** `JSON.stringify` converts typed arrays (like `Uint8Array`) into extremely massive dictionary objects (e.g. `{"0": 1, "1": 0, "2": 1, ...}`) rather than regular arrays. This bloats payload sizes factorially and causes massive lag in serializations. For `this.reach` at N=100 (10,000 values), this took ~400ms per save to serialize, freezing the UI. This issue also applied to `this.adj`, `this.stats`, `this._rawScores`, and `this.currentRanking`.
**Action:** Exclude large `Uint8Array`s and derived/complex properties like `adj`, `stats`, `_rawScores`, and `currentRanking` from local storage save payloads using object destructuring. Reconstruct these values deterministically during restore or when rendering via existing logs (like `matches`).
